# Security Policy

## Supported versions

Topology is pre-1.0. Security fixes land on `main` and on the latest tagged release.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Do not open a public GitHub issue for security reports.

Prefer GitHub's private vulnerability reporting:

https://github.com/jamil2018/topology/security/advisories/new

If that form is unavailable, email Hasnat Jamil at hasnatjamil2018@gmail.com with:

- A description of the issue and its impact
- Affected version or commit
- Steps to reproduce, or a proof of concept

You should receive an acknowledgement, then updates while we investigate and ship a fix. Please do not disclose the issue publicly until a release or advisory is published.
